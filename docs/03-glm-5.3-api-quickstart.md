# GLM 5.3 API Quickstart

Get a GLM 5.3 abliterated or uncensored model running through 7API in a few minutes.

## 1. Create an account and copy two values

Go to **[7api.st](https://7api.st/?utm_source=github&utm_medium=docs&utm_campaign=glm-5.3-abliterated)** and create an account. From the dashboard, copy:

- **API key** — starts with `sk-`.
- **Base URL** — the exact gateway URL for your account.

```bash
export SEVEN_API_KEY="sk-..."
export SEVEN_API_BASE_URL="https://.../v1"
```

## 2. Copy the GLM 5.3 model ID

Open the model list in the dashboard and copy the exact ID for the GLM 5.3 variant you want:

- standard GLM 5.3;
- GLM 5.3 abliterated;
- GLM 5.3 uncensored, where available.

Do not guess the ID from the family name. A `404 model_not_found` usually means the ID was renamed or retired.

## 3. OpenAI-compatible request

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["SEVEN_API_KEY"],
    base_url=os.environ["SEVEN_API_BASE_URL"],
)

response = client.chat.completions.create(
    model="GLM_5_3_MODEL_ID",
    messages=[
        {"role": "system", "content": "You are a precise coding assistant."},
        {"role": "user", "content": "Review this function and list three improvements: ..."},
    ],
)

print(response.choices[0].message.content)
```

## 4. Anthropic-compatible request

```python
import os
from anthropic import Anthropic

client = Anthropic(
    api_key=os.environ["SEVEN_API_KEY"],
    base_url=os.environ["SEVEN_API_BASE_URL"],  # use the Anthropic base URL from the dashboard
)

message = client.messages.create(
    model="GLM_5_3_MODEL_ID",
    max_tokens=1024,
    system="You are a precise coding assistant.",
    messages=[{"role": "user", "content": "Write a migration plan for this module."}],
)

print(message.content[0].text)
```

## 5. cURL

```bash
curl "$SEVEN_API_BASE_URL/chat/completions" \
  -H "Authorization: Bearer $SEVEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "GLM_5_3_MODEL_ID",
    "messages": [{"role": "user", "content": "Hello from GLM 5.3."}]
  }'
```

## 6. Streaming

```python
stream = client.chat.completions.create(
    model="GLM_5_3_MODEL_ID",
    messages=[{"role": "user", "content": "Explain abliteration in five bullets."}],
    stream=True,
)

for chunk in stream:
    text = chunk.choices[0].delta.content
    if text:
        print(text, end="", flush=True)
```

Streaming support depends on the model. Disable it if a model does not stream.

## Common first-run issues

| Symptom | Likely cause | Fix |
|---|---|---|
| `401` | Missing or wrong key | Re-copy the key; check `Authorization` |
| `404` on every path | Wrong base URL | Copy the exact URL from the dashboard |
| `404 model_not_found` | Old model ID | Copy the current GLM 5.3 ID |
| `429` | Rate or balance limit | Back off; check usage/balance |
| Empty stream | Model does not stream | Disable streaming |
