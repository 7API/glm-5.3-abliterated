# GLM 5.3 with Claude Code, Cursor, OpenCode and Codex CLI

GLM 5.3 works with the same compatible endpoints as the other 7API models. Use the exact GLM 5.3 model ID from the dashboard.

## Claude Code

```bash
export ANTHROPIC_BASE_URL="https://.../v1"
export ANTHROPIC_AUTH_TOKEN="sk-..."   # some versions use ANTHROPIC_API_KEY
export ANTHROPIC_MODEL="GLM_5_3_MODEL_ID"
claude
```

If Claude Code ignores the URL, confirm the variables are set in the shell that launches it and that your version expects the auth variable you used.

## Cursor

1. Open **Cursor Settings → Models**.
2. Add your 7API key as the OpenAI API key.
3. Enable **Override OpenAI Base URL** and paste the OpenAI-compatible URL.
4. Add the GLM 5.3 model ID.
5. Test with a small prompt and confirm it appears in 7API usage.

## OpenCode

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "7api": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "7API",
      "options": {
        "baseURL": "https://.../v1",
        "apiKey": "{env:SEVEN_API_KEY}"
      },
      "models": {
        "GLM_5_3_MODEL_ID": {
          "name": "GLM 5.3"
        }
      }
    }
  }
}
```

## Codex CLI

`~/.codex/config.toml`:

```toml
model = "GLM_5_3_MODEL_ID"
model_provider = "7api"

[model_providers.7api]
name = "7API"
base_url = "https://.../v1"
env_key = "SEVEN_API_KEY"
```

```bash
export SEVEN_API_KEY="sk-..."
```

## Which GLM 5.3 variant should a coding agent use?

- **Standard GLM 5.3** — predictable defaults for production coding.
- **GLM 5.3 abliterated** — experiments where refusal behavior blocks agent loops.
- **GLM 5.3 uncensored** — creative or research-heavy work where the recipe matters less than the outcome.

Keep a fallback model configured. If a variant is unavailable, the agent can continue with a standard GLM 5.3 or another family.

## Security checklist

- [ ] Key in an environment variable or secrets manager.
- [ ] No key committed to `opencode.json`, `config.toml` or shell history.
- [ ] Exact base URL from the dashboard.
- [ ] Exact GLM 5.3 model ID from the dashboard.
- [ ] Subkey for shared machines or teammates.
- [ ] Usage and balance monitored.
